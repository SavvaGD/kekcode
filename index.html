🐸 Кек код

эзотерический язык программирования для настоящих кексов

📖 О языке

Кек код — это минималистичный язык, где каждая команда пишется с маленькой буквы. Аргументы всегда идут на следующей строке, без пробелов и лишних символов. Никаких скобок, никаких запятых — только команда и строка аргумента.

⚙️ Правила синтаксиса

1. Все команды пишутся с маленькой буквы. Пример: пукнуть, а не Пукнуть.
2. Аргумент команды пишется на следующей строке.
3. Для многострочных текстов просто пишите текст в следующей строке сколько угодно — он идёт целиком до следующей команды.
4. Комментарии не поддерживаются. Кек код не для слабонервных.

📚 Команды

изменить заголовок
Изменяет заголовок окна на заданный.
изменить заголовок
[новый заголовок]
▶ Пример:
изменить заголовок Моя супер программа
пукнуть
Издаёт звук пука. Аргументом можно указать громкость (от 1 до 100, по умолчанию 42).
пукнуть
[громкость]
▶ Пример:
пукнуть 69
переместить Васю
Перемещает точку (или курсор, или Васю) на экране. Первый аргумент — X, второй — Y. Координаты в пикселях.
переместить Васю
[x]
[y]
▶ Пример:
переместить Васю 300 500
сказать
Превращает текст в речь (синтезатор голоса). Один аргумент — фраза для озвучки.
сказать
[текст]
▶ Пример:
сказать Привет, я кек код, и я умею говорить!
написать
Отправляет сообщение контакту. Первый аргумент — номер телефона, второй — текст сообщения. Только если приложение запущено на Android с разрешениями.
написать
[номер телефона]
[сообщение]
▶ Пример:
написать +71234567890 Привет, это кек код!
изменить переменную
Меняет значение переменной. Если переменной не существует, она создаётся. Первый аргумент — имя переменной, второй — новое значение.
изменить переменную
[имя]
[значение]
▶ Пример:
изменить переменную счёт 10
ждать ввод
Останавливает программу и ждёт, пока пользователь нажмёт Enter (или кнопку «Ввод»). Прочитанный текст сохраняется в переменную, указанную аргументом.
ждать ввод
[переменная]
▶ Пример:
ждать ввод ответ
получить пароль
Читает то, что пользователь ввёл в поле «пароль» (обычно из скрытого поля ввода). Не ждёт ввода, просто берёт текущее значение. Аргумент — переменная для сохранения.
получить пароль
[переменная]
▶ Пример:
получить пароль пароль_юзера
подождать
Приостанавливает выполнение программы на заданное количество тиков. 1000 тиков = 1 секунда.
подождать
[тики]
▶ Пример:
подождать 2000
